# 예약번호 검증

게스트가 "예약 확인" 페이지에서 예약번호를 입력할 때 사용되는 검증 규칙.
예약번호 형식은 BK + 숫자 8자리 (예: BK12345678)

---

## 유효한 예약번호

- BK12345678 입력 → 유효하다고 판단해야 한다
- BK00000000 입력 → 유효하다고 판단해야 한다

---

## 유효하지 않은 예약번호

- 옛날 형식 BK1780053903092(13자리) 입력 → 유효하지 않다고 판단해야 한다
- 숫자가 7자리(BK1234567)이면 → 유효하지 않다고 판단해야 한다
- 숫자가 9자리(BK123456789)이면 → 유효하지 않다고 판단해야 한다
- 소문자로 입력(bk12345678)하면 → 유효하지 않다고 판단해야 한다
- 빈 문자열이면 → 유효하지 않다고 판단해야 한다

---

## 입력 필터 (타이핑 중 자동 처리)

- 소문자로 타이핑하면 → 자동으로 대문자로 바뀌어야 한다
- 특수문자(하이픈 등)가 포함되어 있으면 → 자동으로 제거되어야 한다

---

## 전화번호 검증

- 010-1234-5678 형식 → 유효하다고 판단해야 한다
- 하이픈 없이 숫자만(01012345678) 입력 → 유효하지 않다고 판단해야 한다
- 빈 문자열 → 유효하지 않다고 판단해야 한다

---

## 전화번호 자동 포맷 (타이핑 중 자동 처리)

- 숫자 11자리를 입력하면 → 010-1234-5678 형식으로 자동 변환되어야 한다
- 숫자 4자리만 입력 중이면 → 010-1 처럼 중간 포맷으로 표시되어야 한다
- 12자리 이상 입력하면 → 앞 11자리만 유지되어야 한다
