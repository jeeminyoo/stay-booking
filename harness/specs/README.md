# 테스트 명세서 작성 가이드

이 폴더의 `.md` 파일들을 수정하면 됩니다.  
코드는 몰라도 됩니다. 한국어로 "이렇게 동작해야 한다"고 적으면 Claude가 테스트 코드로 변환합니다.

---

## 작성 규칙

```
# 기능 이름

## 그룹 이름 (선택)

- 상황 설명 → 기대 결과
```

**화살표(`→`) 앞**: 어떤 상황인지  
**화살표(`→`) 뒤**: 어떻게 되어야 하는지

---

## 예시

```
- 예약번호 BK12345678 입력 → 유효하다고 판단해야 한다
- 예약번호가 비어있으면 → 유효하지 않다고 판단해야 한다
```

---

## 수정 후 할 일

1. 이 폴더의 `.md` 파일을 원하는 대로 수정
2. Claude에게 "스펙 반영해줘" 라고 말하면 테스트 코드로 자동 변환
