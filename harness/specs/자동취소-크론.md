# 자동취소 크론 API

10분~1일마다 자동으로 실행되어 마감 시각이 지난 예약을 취소 처리하는 API.
(`/api/cron/expire`)

---

## 보안 인증

- 인증 헤더 없이 요청하면 → 401 오류를 반환해야 한다
- 잘못된 시크릿으로 요청하면 → 401 오류를 반환해야 한다
- 올바른 시크릿으로 요청하면 → 200 응답과 함께 `{ ok: true }`를 반환해야 한다

---

## 자동취소 처리 조건

- 올바른 시크릿으로 요청하면 → "입금 대기(waiting_for_deposit)" 상태이면서 마감 시각이 지난 예약만 취소 처리해야 한다

---

## 오류 처리

- 데이터베이스 오류가 발생하면 → 500 오류를 반환해야 한다
